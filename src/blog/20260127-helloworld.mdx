Welcome to my _new blog_ about different topics around cloud computing,
my bioinformatics background and European sovereign solutions! It's my first blog and it was born out of multiple reasons: I wanted to start sharing things I've learned without relying on social media, which is increasingly flooded with AI generated content. The world is changing rapidly with ongoing conflicts, so I hope to be able to contribute more to open source and sovereign initiatives in the future to reduce dependency on a few big players.

The source code of this website is available on [GitHub](https://github.com/jamand/jamand-webpage). I further describe some implementation details under [the project section](/projects/personal-website/). It's worth noting that I'm not primarily a frontend developer, it's an ongoing project created _learning by doing_. For transparency reasons I'd like to state that I worked in tandem with Claude Code, especially for finding the right layout classes in TailwindCSS/DaisyUI. The content is written and translated by myself.

I have a few articles in the pipeline I'd like to share and improvements to my blog that I planned, among others:

- Explain what bioinformatics is (from my biased point of view). A frequently asked question among friends and colleagues.
- Present a few of my favorite European alternatives to commonly used web services.
- Add [giscus](https://github.com/giscus/giscus) as comment feature below blog posts.

Stay tuned and have a nice day!
